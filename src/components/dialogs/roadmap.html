Poppy Roadmap: 6.0 to 11.0

Future Blooms

Poppy, six blooms from here.

Poppy 5.0 turns a sentence into a working app. The next six versions teach those apps to remember, listen, sync, adapt, act and spread. Count the petals: each bloom carries its version number.

6.0 · Rewind Timeline Engine

Every site gets a timeline, so no build is ever a one-shot.

  • Scrub through any build like a video and see exactly when the app changed.
  • Branch from any frame to try a different idea without losing the one you love.
  • A visual diff shows which pixels moved and the exact code behind them.
poppy.history.fork("frame-12", { name: "dark theme" });

Why it matters: A build stops being a result and becomes a workspace with memory.

7.0 · Sketch Multimodal Input

Draw it, say it, point at it. Poppy builds from whatever you have in hand.

  • Sketch on a canvas or drop in a whiteboard photo and get real components, not a traced image.
  • Talk through a screen out loud and watch it assemble as you speak.
  • Tap anything in a live app and say "make this a drawer" to change just that part.
const part = await poppy.lens.pick();
await poppy.ai("turn this into a drawer", { target: part });

Why it matters: The text prompt box is no longer the only way in.

8.0 · Mesh Serverless P2P CRDT

Every app is multiplayer by default, with or without a connection.

  • Shared state merges instead of overwriting, built on the same WebRTC rooms Poppy already uses.
  • Edits made offline on a phone and a laptop reconcile when either comes back online.
  • Share a link and collaborators get cursors, presence, and comments for free.
const board = await poppy.sync("board", { merge: "crdt" });
board.on("change", render);

Why it matters: Collaboration moves from a game feature into the foundation of every app.

9.0 · Organisms Self-Improvement

Apps that notice where people struggle and quietly propose a fix.

  • Friction sensing spots dead taps, rage clicks, and abandoned flows with on-device data.
  • Poppy drafts a patch, runs the verify probe on it, and shows a before and after.
  • Approve with one tap, or let fixes you trust apply themselves autonomously.
poppy.evolve.watch({ signals: ["dead-tap", "rage-click"] });
poppy.evolve.onProposal(p => p.preview());

Why it matters: Self-repair grows into self-improvement; the app keeps getting better after shipping.

10.0 · Agents Local WebGPU Hands

Give apps hands, with a leash you control.

  • Tool-using agents run on local WebGPU models and fall back to the cloud when needed.
  • Each app declares what it may touch, and every action lands in a revocable ledger.
  • Agents drive other Poppy apps through the same typed contracts verify-contracts already checks.
const agent = poppy.agent({ can: ["store.read", "notify"] });
await agent.run("remind me when stock runs low");

Why it matters: Apps shift from showing information to acting on it safely.

11.0 · Commons Signed Remix Graph

A remix graph for single-file software.

  • Publish signed cartridges that carry provenance and trace every fork back to its root.
  • Pull in versioned blocks like a leaderboard, synth, or P2P lobby, and compose them like parts.
  • Credit flows back through the graph, so one good idea lives inside a thousand remixes.
const lobby = await poppy.use("block:@you/lobby@2");
lobby.mount("#players");

Why it matters: Poppy grows into a place where software compounds and connects.

5.1A Stricter Verify Probe

Checks contrast, tap-target size, keyboard focus, and frame-time budgets, then repairs whatever fails.

5.2The Starter Shelf

Hand-tuned starting points, like a kanban board, a synth, a tank duel, and a pitch deck, to remix instead of prompting from nothing.

5.3Size and Cost Meter

Shows how heavy an app is and how many AI calls it makes before you share it.

5.4Explain Mode

Hover any element and Poppy says in plain words what its code does.

5.5Export Presets

Remember the target you always pick, like a PWA for phones or Tauri for desktop, per project.

Ideas and experiments that have not been promised a version number yet:

Poppy Reality Export any app to WebXR so an interactive dashboard or 3D tool can float above your desk.
Poppy Tutor A build mode that narrates each design decision and quizzes you on the code it just wrote.
Poppy Pocket Fully offline builds on a phone, powered by an efficient on-device small language model.
Poppy Hardware WebSerial, WebUSB, and Bluetooth bridges so apps can talk directly to Arduino and ESP32 boards.
Poppy Sound Audio-first generative apps, synths, and reactive instruments built natively on Web Audio API.
Poppy Classroom Shared workspaces where teachers and teams can scrub through student timelines and collaborate.

What Never Changes · Six Permanent Promises

  • One file stays one file: Every app can still ship as a standalone HTML file.
  • Offline first: Nothing needs a server unless you explicitly add one.
  • Your data stays yours: Stores and friction signals live on your device.
  • No dead buttons: The zero-dead-button guarantee only gets stricter.
  • Old apps keep running: Anything built on 5.0 works in all future versions.
  • You approve what changes: Patches, agent actions, and publishes wait for your yes.
